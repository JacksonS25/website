# Jackson's Coding Wonderland
A website where you can interact with my backend projects. Some will be directly useful to the user, others will simply be fun interactions!

## Motivation
Initially I simply wanted a way to use my Song_Set_Maker from my phone, so I didn't have to load up the computer any time I wanted to generate a worship set list.
Then it evolved into the idea to make a website that could host many of my backend projects to allow of ease of use for me and the potential to help others and display what they can do.

## Quick Start
https://jacksons-coding-wonderland.onrender.com/

Access the above link and you will find an easy to use command line interface where you can select a project, enter its arguements, and then see how it executes.

## 🤝 Contributing

### Additional Backend Projects worth schowcasing?

It is unlikely I will include others backend projects, but if there is a backend project you believe is worth showcasing and want to do it here,
then you can send me message and explain the project to me. If it is particularly useful or creative, I may add it under a separate page where it will be accredited to you and used from there.
